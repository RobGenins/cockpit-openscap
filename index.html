Getting Started - Step by Step Guide

1
Run a Scan (Tab 1)

Select a security profile (e.g., DISA STIG) and click "Run Compliance Scan". The scan takes 5-15 minutes. When complete, your HTML report opens automatically and all files are saved to ~/Downloads/ComplianceResults/

2
Review Results

The HTML report shows your compliance score, passed/failed checks, and detailed findings. Review the failed items to understand what needs fixing.

3
Build Custom Remediation (Tab 2)

Select specific findings you want to fix, then generate a Bash script or Ansible playbook containing only those fixes. This gives you control over what changes are made.

4
Apply Fixes Carefully

Review the generated script before running it! Execute with sudo bash script-name.sh. Some fixes may require a reboot. Re-scan afterward to verify improvements.

Where Are My Files?

All scan outputs are saved to: ~/Downloads/ComplianceResults/

  • report-{scanId}.html - Full compliance report (open in browser)
  • xccdf-results-{scanId}.xml - Raw results for auditors/tools
  • remediation-{scanId}.sh - Bash script to fix ALL findings
  • playbook-{scanId}.yml - Ansible playbook to fix ALL findings
  • custom-remediation-*.sh - Your custom scripts from Tab 2

Previous files are automatically moved to the Archive/ subfolder.
