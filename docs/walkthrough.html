1. Overview

OpenSCAP Cockpit Plugin transforms security compliance scanning from a complex command-line process into an intuitive visual experience. Built for enterprise environments running RHEL, CentOS, Rocky Linux, AlmaLinux, or Fedora.

🔍

One-Click Scanning

Run DISA STIG compliance scans with a single click

🛠️

Selective Remediation

Choose exactly which findings to fix - no all-or-nothing

📊

Visual Dashboard

Track compliance trends with animated charts

⏰

Automated Scheduling

Set up recurring scans without cron knowledge

📜

Dual Script Output

Generate both Bash and Ansible remediation scripts

📁

Complete History

All scans saved and accessible forever

After installation, open your browser and navigate to https://your-server:9090. Login with your system credentials, then click "OpenSCAP" in the left navigation menu.

8. Recommended Workflow

Follow this workflow for effective compliance management:

1

Initial Scan

Go to Tab 1 and run your first scan to establish a baseline. Review the HTML report to understand your current compliance posture.

2

Create Snapshot/Backup

Critical! Before any remediation, create a VM snapshot, LVM snapshot, or full backup. Remediation can break things.

3

Selective Remediation

Go to Tab 2 and carefully select which findings to fix. Start with high-severity items. Generate a custom script with only selected fixes.

4

Review & Apply

Review the generated script, understand each fix, then run it. Test in non-production first if possible.

5

Rescan & Verify

Run another scan from Tab 1 to verify fixes were applied. Check Tab 4 dashboard to see improvement.

6

Schedule Ongoing Scans

Use Tab 5 to set up weekly or monthly automated scans. This ensures continuous compliance monitoring.

7

Monitor Dashboard

Regularly check Tab 4 to track compliance trends. The dashboard shows if you're improving or declining over time.
